#  Jogo da Velha em Unity

Um simples jogo da velha (tic-tac-toe) desenvolvido em **Unity** para fins de aprendizado e prática de programação em C#.

---

##  Funcionalidades
- [Tabuleiro interativo](ca://s?q=Detalhes_do_tabuleiro_interativo) 3x3.
- [Dois modos de jogo](ca://s?q=Explicar_modos_de_jogo): 
  - Jogador vs Jogador.
  - Jogador vs Computador (IA básica).
- [Detecção automática de vitória](ca://s?q=Como_funciona_a_deteccao_de_vitoria) ou empate.
- Reinício rápido da partida.
